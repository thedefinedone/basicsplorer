# Basicsplorer

Retro 90s terminal-style file manager and disk utility for Android, built using Jetpack Compose.

## Features
- **Arcade Boot Screen**: Classic "PRESS ANYWHERE TO START" splash screen.
- **Storage Cleaner**: Terminal output listing logs, temp files, duplicates (>1MB), and orphaned data for cleanup.
- **System Analyser**: ASCII sector map and disk space distribution bars.
- **File Explorer**: High-contrast directory navigation optimised for touch.
- **Offline & Private**: Works completely offline without telemetry, tracking, or network permissions.

## Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Target OS**: Android
